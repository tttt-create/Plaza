# Hidden in Plain Sight

Hidden in Plain Sight is a mobile-friendly browser game built as a dark-comedy management sim. The player operates a social platform and wins by building valuation through data extraction, not conventional ad revenue.

## Core loop
- Turn product levers on to harvest specific data types
- Combine raw data into inferences
- Unlock additional levers from inference outcomes
- Grow revenue toward the $100B valuation target
- Stay below the public-awareness threshold or lose the run

## Key systems
- 10 starting data types with stockpiles
- 15 inferences with explicit recipes
- Mutually exclusive inference branches
- Awareness pressure, regulator investigation, and press pressure
- Countermeasures: lobbying, rebrand, privacy theater
- Dossier-based win/lose screens centered on Mara Ellison
